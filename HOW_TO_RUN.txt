1. HOW TO START THE SERVER:
   Double-click:  START_SERVER.bat
   - Starts the server and Cloudflare tunnel engine.
   - Automatically syncs the secure link to all tablets worldwide!
   - Opens the official Live Cloud Portal: https://is.gd/westernintapplock
   - Leave the black window open or minimized.

2. HOW TO REMOVE A DAMAGED OR UNWANTED TABLET:
   METHOD A (From Browser Portal):
   - On the login screen or in the top header, click:
     "[🗑️ Manage Fleet / Remove Tablet]"
   - In the Fleet Manager popup, click "Delete" next to any tablet
     (e.g., SHOLA TEST TAB [WIG-F746D0]).
   - Or type the Device ID in "Force Remove Tablet by ID" and click Delete.
   - Or click "[Purge All Offline Tablets]" to remove all offline devices at once.
   - Admin Code: 7866 (or Wf@3125210946).

   METHOD B (From Windows 1-Click Script):
   - Double-click:  RESET_DEVICES_LIST.bat
   - This immediately clears all offline and damaged tablets from Windows!

3. HOW TO CHECK STATUS:
   Double-click:  CHECK_STATUS.bat
   - Displays server status and the active Cloudflare HTTPS link.

4. HOW TO STOP THE SERVER:
   Double-click:  STOP_SERVER.bat

5. AUTO-START ON LAPTOP BOOT:
   Double-click:  ENABLE_AUTO_START.bat
   - Runs server silently in background whenever the laptop restarts.
